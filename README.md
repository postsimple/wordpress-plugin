# PostSimple WordPress Plugin

Verzend je WordPress posts met één klik naar PostSimple om automatisch professionele social media content te genereren.

## Over PostSimple

[PostSimple](https://postsimple.app) is dé AI social media tool voor automatische social media posts en slimme social media planning. PostSimple maakt en plaatst content in de stijl van je bedrijf, afgestemd op elk social media kanaal.

Met deze WordPress plugin kun je eenvoudig je WordPress content delen met PostSimple, waar het wordt omgezet naar pakkende social media posts die perfect aansluiten bij jouw huisstijl en doelgroep.

## Vereisten

- WordPress 5.0 of hoger
- PHP 7.2 of hoger
- **PostSimple Pro abonnement** met API toegang
- PostSimple API key (aan te vragen via [api@postsimple.nl](mailto:api@postsimple.nl))

> **Let op:** De API key is alleen beschikbaar in combinatie met een Pro-abonnement. Heb je nog geen Pro-abonnement? Upgrade dan eerst je account op [PostSimple](https://postsimple.app).

## Installatie

### Via WordPress Admin (aanbevolen)
1. Download het ZIP bestand van deze plugin
2. Ga naar **Plugins → Nieuwe plugin → Plugin uploaden**
3. Upload het ZIP bestand en klik op "Nu installeren"
4. Klik op "Plugin activeren"

### Handmatige installatie
1. Download en pak het ZIP bestand uit
2. Upload de `postsimple-wordpress` map naar `/wp-content/plugins/`
3. Ga naar **Plugins** in WordPress
4. Activeer "PostSimple WordPress Integration"

## Configuratie

### Stap 1: Vraag je API key aan
1. Zorg dat je een **PostSimple Pro abonnement** hebt
2. Stuur een e-mail naar **api@postsimple.nl** met:
   - Je bedrijfsnaam
   - Het e-mailadres van je PostSimple account
   - De URL van je WordPress website
3. Je ontvangt binnen 1-2 werkdagen je persoonlijke API key

### Stap 2: Configureer de plugin
1. Ga naar **Instellingen → PostSimple** in WordPress
2. Plak je API key in het veld
3. Klik op **"Instellingen opslaan"**

## Gebruik

1. Maak of bewerk een post, pagina of ander content type in WordPress
2. Zoek de **PostSimple** meta box in de sidebar (rechterkant van het scherm)
3. Klik op de knop **"Verzend naar PostSimple"**
4. Je wordt automatisch doorverwezen naar PostSimple waar je de gegenereerde social media content kunt bekijken en aanpassen

## Veelgestelde vragen

### Hoe krijg ik een API key?
De API key is beschikbaar voor PostSimple Pro klanten. Stuur een e-mail naar api@postsimple.nl om je API key aan te vragen.

### Werkt de plugin met Gutenberg en Classic Editor?
Ja! De plugin werkt met zowel de Gutenberg block editor als de Classic Editor.

### Kan ik meerdere posts tegelijk verzenden?
Momenteel ondersteunt de plugin het verzenden van één post per keer. Bulk verzenden komt in een toekomstige update.

### Wat gebeurt er met mijn post na verzenden?
Je WordPress post wordt niet aangepast. De titel en URL worden naar PostSimple gestuurd, waar AI automatisch social media content genereert op basis van je instellingen.

### Kan ik concepten verzenden?
Ja, je kunt posts in elke status verzenden (concept, gepland, gepubliceerd). PostSimple gebruikt de titel en URL van je post.
